# Getting started
{: .no_toc }

1. TOC
{:toc}

## The window

The sidebar has six pages:

| Page | What it's for |
|:--|:--|
| **Overview** | Library health at a glance, and the **Scan now** button |
| **Review** | Every change the last scan proposes, in groups |
| **Playlists** | Build a folder tree of playlists from your tags |
| **Automation** | Let the app keep things in step on its own |
| **Activity** | Everything the app has done, with details |
| **Settings** | Watch folders, file types, library file, theme, About |

## 1. Add a watch folder

*Watch folders* are where your music files live. The app looks in them for new and moved files.

On the first start, the Overview page suggests the folder your library's music is already in.
Click **Watch this folder**, or **Choose a folder...** to pick another one. You can add more
later in [Settings](settings#watch-folders).

Adding a folder starts the first scan.

## 2. Scan

Click **Scan now** on the Overview page. The scan only **reads**: it checks every track in your
library and every audio file in your watch folders. Nothing in iTunes changes.

When it's done, the Overview shows how many items it found in each group:
**New files**, **Moved files**, **Missing files**, **Tag updates** and **Unavailable**.

## 3. Review and apply

You have two choices:

- **Apply all changes** applies everything at once. A dialog lists each group so you can untick
  any you want to leave for now.
- **Review** each group first and apply only the items you pick. See [Review](review).

While a task runs, a progress bar shows at the bottom of the window. You can cancel it, and you
can keep using iTunes in the meantime. iTunes' view refreshes by itself afterwards.

## 4. Optional extras

- [Playlists](playlists): build *Albums by Artist* style playlist folders.
- [Automation](automation): scan and apply by itself when your folders change.

## Opening and closing

- **Closing the window quits the app**, after any running task finishes.
- If **automation** is on, closing the window keeps the app running in the
  **notification area** (system tray) instead. Click the tray icon to open it again. To stop it,
  use **Quit app** at the bottom of the sidebar or in the tray icon's menu.
- Starting the app while it's already running brings the open window to the front.
